# Cykl życia pamięci

`WORKING_STATE.md` jest krótką, często aktualizowaną pamięcią roboczą.

Pamięć trwałą zapisuj tylko dla informacji przydatnych w przyszłych sesjach: decyzji, ograniczeń, root cause, gotchas, kosztownych błędnych podejść i hipotez.

Hipoteza nie jest faktem i powinna pozostać `tentative` do weryfikacji.

Jeżeli pamięć przeczy aktualnemu kodowi/testom: ufaj kodowi, oznacz starą pamięć jako `superseded`/`invalid`, zapisz nowe dowody i odśwież indeks.
